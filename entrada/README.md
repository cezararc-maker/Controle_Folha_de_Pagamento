# Entrada da planilha-fonte

Adicione aqui, pelo GitHub, a pasta de trabalho original que será usada como fonte do protótipo.

Requisitos:

- usar o arquivo original, preferencialmente `.xlsm`, sem conversão;
- fechar o Excel antes de enviar, evitando arquivo temporário `~$`;
- não remover macros, consultas, conexões ou vínculos;
- informar no commit que se trata da cópia-base para diagnóstico;
- não incluir senhas, credenciais ou dados pessoais que não sejam necessários ao teste.

Nenhum script do projeto modifica arquivos desta pasta. Futuras versões geradas deverão ficar em uma pasta separada e nunca sobrescrever a origem.
